# Preview Run Doc

## How to reproduce artifacts
1. Dependencies are installed via `npm install`.
2. Copy `me.jpeg`, `Kamyomobong_Resume_Updated.pdf`, `image.png` to `public/` if missing.

## How to run the server
1. Start the dev server:
   ```bash
   npm run dev
   ```
2. Next.js starts on a random port. Check terminal output for the actual URL.
3. Current session URL: http://localhost:54652
